# 蓝鲸任务台账修复说明

> 适用：`dsh-task-ledger` 0.1.8 + 本机 Windows 11（智能应用控制开启）。
> 症状：① 加载技能报 `loaded skill "task-ledger" source must be a string`；② 面板/命令报 `spawn UNKNOWN` 或「应用程序控制策略已阻止此文件」。

---

## 一、根因

| # | 问题 | 证据 | 为什么不能简单绕过 |
|---|---|---|---|
| 1 | 技能注册对象缺字段 | DSH 新版要求 `source` / `provider` 为 string；插件只传 `name/description/content/path` | 改插件注册代码即可 |
| 2 | 未签名 Go 二进制被拦截 | 事件日志 `CodeIntegrity 3077`：`ledger-windows-amd64.exe ... did not meet Enterprise signing level requirements (Policy ID:{0283ac0f...})`；`VerifiedAndReputablePolicyState=1` | 这是 Smart App Control（SAC），只能重置/重装 Windows 关闭，不能加白单个程序；复制/改名/换目录都无效 |

结论：**原二进制在这台机器上永远跑不起来**；必须换一个由已签名宿主执行的实现。

---

## 二、补丁清单（4 处）

### 1. 技能注册：`dist/host/skill/registration.js`

把返回值从：

```js
return { name, description, content, path: `${skillDir}/SKILL.md` };
```

改成：

```js
return {
    name,
    description,
    source: "dsh-task-ledger",
    provider: "dsh-task-ledger",
    invocation: { modelInvocable: true, userInvocable: true },
    content,
    path: `${skillDir}/SKILL.md`,
};
```

### 2. 执行器：`dist/host/repositories/runner.js`

Windows 不再 spawn `.exe`，改为 spawn Python：

```js
function pythonPath() {
    const candidates = [
        process.env.DSH_PYTHON,
        join(process.env.USERPROFILE || homedir(), ".dsh", "dsh-runtimes", "dsh-primary-runtime",
            "dependencies", "python", "python.exe"),
        "python",
    ].filter(Boolean);
    for (const c of candidates) if (c === "python" || existsSync(c)) return c;
    return "python";
}
function defaultScriptPath() {
    if (process.platform === "win32")
        return fileURLToPath(new URL("../../../skill/ledger.py", import.meta.url));
    return fileURLToPath(new URL("../../../skill/scripts/progress", import.meta.url));
}
```

`exec()` 里：

```js
const isPython = scriptPath.toLowerCase().endsWith(".py");
const command = isPython ? pythonPath() : scriptPath;
const commandArgs = isPython ? [scriptPath, sub, ...args] : [sub, ...args];
const child = spawn(command, commandArgs, { stdio: ["ignore", "pipe", "pipe"], env: ... });
```

### 3. init 命令展示：`dist/host/routes.js`

```js
const head = process.platform === "win32"
    ? `"${interpreterPath()}" "${entry}" init`
    : `sh "${entry}" init`;
```

（`interpreterPath` 从 `runner.js` 导入。）

### 4. 技能调用说明：`skill/SKILL.md`

「怎么调用」改为：

```bash
"C:\Users\whj\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" \
  "C:\Users\whj\.dsh\profiles\desktop\node_modules\dsh-task-ledger\skill\ledger.py" \
  <子命令> --repo <工作区根>
```

保留 `scripts/progress` 的说明，因为 `registration.js` 会校验这个字符串存在。

## 三、Python CLI：`skill/ledger.py`

- 存储：`<repo>/ledger/ledger.json`（tasks / history / owners）
- 过程文档：`<repo>/ledger/worklog/<id>.md`
- 身份：`~/.taskledger/identity.json`
- 目录清单：`~/.taskledger/dirs.json`

已实现命令：

```
init  whoami  root  dirs
new  claim  set  log  close  delete
list  stats  stats --trend  owners  show  history  validate
switch  forget  logout
```

输出字段与插件 `types.d.ts` 对齐；已用插件仓储层验证：

```js
readTasks / readOwners / readStats / readBoardTrend / readHistory
```

全部解析通过（2026-11-09）。

## 四、生效与验证

1. **重启 DSH**（host 模块有 ESM 缓存，禁用/启用插件不会重新加载改过的代码）。
2. 打开台账面板，应能看到工作区 `D:\寻迹` 与 12 条任务（1 doing + 11 open + 1 done）。
3. 命令行验证：

```powershell
& "<python>" "<skill>/ledger.py" stats --repo "D:\寻迹" --json
& "<python>" "<skill>/ledger.py" list --repo "D:\寻迹" --json
```

## 五、插件升级后怎么重打

升级会覆盖 `dist/`，但**不会覆盖** `skill/ledger.py`（`skill/` 目录在升级包里也会被覆盖，先备份）。

1. 备份 `skill/ledger.py`。
2. 重新应用上面 4 处补丁。
3. 把 `ledger.py` 放回 `skill/`。
4. 重启 DSH，跑一遍第四节验证。

> 如果未来 Windows 关闭了 SAC 或换到没有 SAC 的机器，可以把 `runner.js` 改回 spawn 原 exe；`ledger.py` 可以保留作为备用。

---

## 六、注意

- 不要为了绕过 SAC 去改 WDAC 策略或关闭系统安全功能；用已签名宿主执行脚本是正路。
- 本补丁不修改台账数据格式，`ledger/` 可随项目备份/迁移。
- 身份文件是全机器共用的；本次已恢复原 uuid，没有重建。
